# README – Sales Dataset Analysis Dashboard

## Project Title

**Sales Dataset Analysis Dashboard**

## Description

This project analyzes sales data to identify key business insights such as revenue trends, top-performing products, regional sales performance, and customer behavior. The dashboard helps users make data-driven decisions by presenting sales information in a clear and interactive format.

## Objectives

* Analyze sales performance.
* Identify top-selling products.
* Monitor revenue trends.
* Compare regional sales.
* Support business decision-making.

## Tools Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* CSV Dataset

## Files Included

* `sales_dataset.csv` – Raw sales data.
* `sales_dataset1.ipynb` – Data analysis notebook.
* `README.md` – Project documentation.

## Features

* Data cleaning and preprocessing
* Sales trend analysis
* Product-wise performance analysis
* Regional sales comparison
* Visualizations and charts

## How to Run

1. Open the Jupyter Notebook (`sales_dataset1.ipynb`).
2. Ensure all required Python libraries are installed.
3. Load the dataset (`sales_dataset.csv`).
4. Run all notebook cells to generate analysis and visualizations.

## Outcome

The dashboard provides meaningful insights into sales performance, helping businesses understand trends, improve strategies, and increase profitability.
